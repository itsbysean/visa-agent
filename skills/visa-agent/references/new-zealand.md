# New Zealand: research starting points

These are discovery links, not a verified requirements list:

- Immigration New Zealand: https://www.immigration.govt.nz/
- Official education information: https://www.studywithnewzealand.govt.nz/

Use the immigration authority's current navigation/search to find the exact route, evidence and application pages. Support all purposes by research rather than assuming a student visa applies. For an initial study case, establish citizenship, current location/status, age, named school/course, course duration and start date, offer status, funding circumstances and accompanying applicants. Look up the named school's own admissions information.

For a Vietnamese applicant, verify the exact nationality/location conditions on current official pages. Do not hard-code financial thresholds, fees, medical/police evidence rules, processing times, work rights, or age cutoffs. Create tasks only after checking applicability; otherwise show a verification task. Include admissions, visa and pre-departure tasks where relevant, with official obligations separated from recommendations.

For other destinations use the same research protocol and add a country reference only when useful. Unsupported browsing or missing route information should produce an explicitly provisional plan, not fabricated rules.
